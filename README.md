# datelc 📅

**datelc** is a simple, lightweight desktop date calculator that makes it easy to calculate date differences and perform date arithmetic through a clean graphical user interface.

## ✨ Features

- 📆 Calculate the difference between two dates.
- ➕ Add days to a specific date.
- ➖ Subtract days from a specific date.
- 🗓️ View date calculations in a clear, readable format.
- 🖥️ Simple and user-friendly desktop interface.
- ⚡ Lightweight and easy to use.


Navigate to the project directory:

```bash
cd datelc
```

Install dependencies and start the application using the commands appropriate for your technology stack.

## 🚀 How to Use

1. Open the datelc desktop application.
2. Select the dates you want to calculate.
3. Choose the desired operation.
4. View your result instantly.

### Available Calculations

- **Date Difference:** Find the number of days between two dates.
- **Add Days:** Calculate a future date by adding days.
- **Subtract Days:** Calculate a previous date by subtracting days.
